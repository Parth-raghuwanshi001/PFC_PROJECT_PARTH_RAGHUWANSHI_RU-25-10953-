Danger Zone Detection System Using 2D Array

**📖 Project Description**
This project is developed using the C programming language to simulate a Danger Zone Detection System.
The program uses a 2D array (matrix) to represent a grid where:
1 represents a Danger Zone
0 represents a Safe Zone
The system scans the entire grid and identifies the positions (row and column) of all danger zones.
This project helps in understanding 2D arrays, nested loops, and condition checking in C.

**🎯 Why This Project Is Created**
To understand 2D array indexing
To practice nested loops
To learn how to analyze matrix data
To implement real-life grid-based problem solving in C

**🛠️ Tools & Technologies Used**
Programming Language: C
Compiler: GCC
Editor: VS Code

**🧠 Concepts Used**
2D Arrays
Nested Loops
Conditional Statements (if)
Functions
Matrix Traversal

**⚙️ How the Program Works (Algorithm)**
Ask the user to enter number of rows and columns
Read rows and columns using scanf
Create a 2D integer array
Take input values (0 for Safe, 1 for Danger)
Pass the array to a function
Use nested loops to scan the matrix
Check each element
If value is 1, print its row and column position
Continue until the entire matrix is scanned
End the program
